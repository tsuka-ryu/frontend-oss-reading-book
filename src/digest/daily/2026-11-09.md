## トップニュース

### oxc の lexer から SIMD 層が `oxc_simd` として独立する

【oxc】oxc-project/oxc の `main` に、2026-11-08（UTC）、overlookmotel による lexer の SIMD まわりの一連のPRが入った。lexer 内にあった `cpu` と `simd` のコードが、新しい `oxc_simd` と `oxc_simd_macros` の crate に移った（#29020）。

**何が変わる**

- `oxc_simd` crate が新設され、`oxc_lexer_macros` crate は消えた（#29020）。
- 実行時の CPU 機能の検出が入った（#28829）。
- AVX2 付きでコンパイルしたバイナリには汎用版のコードを入れず（#28830）、Neon を無効にした aarch64 には Neon のコードを入れない（#28831）。
- テストとconformance が AVX2 版と汎用版の両方で走るようになった（#28871、#29019、#29023）。

**なぜ変えた**

#29020 の本文によると、直接の目的は `#[test_cpus]` マクロを lexer の統合テストで使うこと。あわせて、将来ほかの oxc crate で SIMD を使う道を開くとある。CodSpeed は性能に変化なしと報告している。

**何に効く・誰が困る**

利用者に見える挙動の変更ではなく、テストの網羅性と内部構造の整理。11-08 号の「先読みをやめる」最適化の続きの基盤整備にあたる。

**ここまでの経緯**

- 2026-11-07：パーサー・レキサーの perf が連続してマージされる。[11-08 の号](2026-11-08.md)。
- 2026-11-08：SIMD 層が独立し、CPU ごとのテストが整う。

出典: https://github.com/oxc-project/oxc/pull/29020
